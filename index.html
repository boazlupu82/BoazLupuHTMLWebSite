Designed & implemented / Pull-request guard rules

Better contributions.
Protected production.

Designed and implemented an automated pull-request guard-rule system that validates contributions and delivers actionable feedback before merge, preventing noncompliant or substandard code from reaching production.

Pull-request validationGuard rulesActionable feedbackPre-merge quality gates

The GitHub Actions example demonstrates the approach with linting, TypeScript checks, and tests. Failed checks explain what contributors should run and fix.

name: Pull request guard
on: [pull_request, merge_group]

# Within the PR Guard job:
- name: Validate contribution
  run: |
    npm run lint
    npm run typecheck
    npm test
