Designed & implemented / Project diagnostics

Automation Doctor.
A health check for the whole project.

Built Automation Doctor to scan an automation project and report its health, checking the runtime, installed libraries, framework tooling, browser binaries, and required project files.

It also checks for outdated libraries, available dependency updates, and version conflicts. When a required dependency or file is missing—or incompatible versions are detected—it raises a clear alert and suggests corrective steps, helping developers resolve setup and compatibility issues before running tests.

Project health scanDependency validationOutdated-library detectionUpdate checksVersion-conflict detectionMissing-file alertsSuggested fixes

In the example scan, Automation Doctor confirmed the installed tooling and dependencies, detected a missing Firebase service-account file, and recommended obtaining it through the team’s approved credential distribution process.
